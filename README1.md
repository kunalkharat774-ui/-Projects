# 🛡️ SecureWatch - Web Application & API Security Dashboard

**SecureWatch** is a comprehensive, real-time cyber threat monitoring, analysis, and file protection platform. Built with a sleek dark neon aesthetic, it provides security analysts with instant visibility into global threats, URL safety checks, dynamic file encryption/decryption, and system metrics.

---

## ✨ Features

### 🌐 1. Live 3D Cyber Attack Map
* **Real-Time Visuals:** Interactive 3D globe displaying global attack routes and targeted regions.
* **Attack Metrics:** Track total attacks, successful attempts, blocked threats, and ongoing incidents in real-time.

### 🔍 2. URL Reputation Checker
* Instant scanning of URLs for phishing, malware, spam, and blacklisting status.
* Displays detailed domain information, IP addresses, and safety scores.

### 🔐 3. File Security (Encryption & Decryption)
* **Encrypt Files:** Secure sensitive documents with strong custom passwords before sharing.
* **Decrypt Files:** Easily decrypt incoming protected files directly from the dashboard.
* Supported formats: PDF, XLSX, DOCX, PPTX, and more.

### 📊 4. System & Security Monitoring
* **Dashboard Overview:** Displays total requests, active threats, vulnerabilities, and overall Risk Score (e.g., Medium Risk 72/100).
* **System Status:** Monitors live CPU, Memory, Disk, and Network performance.
* **Navigation Tools:** Includes OWASP Top 10 insights, Email Breach Checker, IP Lookup, Security Logs, and User Management.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 / Tailwind CSS, JavaScript (ES6+)
* **Data Visualization:** Three.js / Globe.gl (for 3D Map), Chart.js
* **Icons:** FontAwesome / Lucide Icons
